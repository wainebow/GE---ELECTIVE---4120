This file showcases a resume generation activity that compares how ChatGPT and Gemini create a one-page professional resume using the exact same personal, educational, and training details. It contains the prompt used, the separate outputs from both AI tools, a side-by-side comparison table, a reflection, and the final formatted resume.

$\color{#FF69B4}{\Large\textbf{୨୧ ₊˚ 🎀 What have I learned? 🎀 ˚₊ ୨୧}}$

</div>

I learned that different AI tools format the same information in very different ways. When I entered my personal details, ChatGPT gave a plain text response that needed manual editing, while Gemini generated a clean and organized resume layout right away.

I also learned how to pick the right AI tool based on what I need for a task. ChatGPT works well if I only want a simple text draft to edit on my own, while Gemini is better when I want a styled document that is ready to use.

Finally, I realized that good formatting and design matter a lot when presenting important information. Proper headings, clean spacing, and visual structure make a resume much easier to read and look more professional.
